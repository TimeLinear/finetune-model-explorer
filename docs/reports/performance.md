## 1. 측정 방법

| 항목 | 내용 |
|---|---|
| 질문 | Q-a "이 모델의 라이선스와 지원 언어를 알려줘", Q-b "이 모델 계열의 학습 방식에 대해 설명해줘" (위키 수집 유발용) |
| 모델 | `kakaocorp/kanana-1.5-8b-instruct-2505`, `meta-llama/Llama-3.2-11B-Vision-Instruct` |
| 상태 | 콜드: 그 모델·그 질문으로 처음 묻는 상태 / 웜: 바로 이어서 같은 질문을 한 번 더 |
| 콜드 재현 | `data/chroma`를 ASCII 경로에 복사하고, **사본에서만** 위키 청크 64개·위키 수집 기록·위키 본문 캐시를 지운 기준 사본을 만듦. 세션마다 기준 사본을 새로 복사해 `CHROMA_DIR`로 지정. 원본 `data/chroma`는 수정하지 않음 (원본 문서 청크 4,731개 유지) |
| 실행 방식 | ① Streamlit 앱, 파일 감시 켬(기본값) ② Streamlit 앱, `--server.fileWatcherType none`(실행 옵션) ③ Streamlit 없이 같은 순서(카드 색인 확인 → 위키 수집 → 그래프)로 호출하는 스크립트 |
| 세션 구성 | 한 세션 = 프로세스 1개 + 새 콜드 사본. 순서: kanana Q-a 콜드 → 웜 → Q-b 콜드 → 웜 → Llama 같은 순서 (앱처럼 모델별 대화 기록이 쌓임) |
| 반복 | 실행 방식마다 **2회** (총 6세션, 48건). 세 번째 측정은 당시 API 프록시 사용 한도 때문에 **미측정**: 1세션이 한도의 약 14~19%(세션별 14.3·14.6·14.2·15.3·16.5·18.9%)를 써서 세 번째까지 하면 한도를 넘음 |
| 기록 | 서버: `logs/perf.jsonl` (질문 1건 = 1줄, 단계별 시간·LLM 호출별 용도·모델·토큰·시간). 화면 기준: 브라우저에서 전송 버튼을 누른 때부터 답변의 근거 목록이 화면에 나타날 때까지 (앱만) |
| 주의 | 화면 기준 시간은 브라우저 창이 가려진 상태에서 잰 측정이 있어 오차가 있을 수 있다. 앱 "파일 감시 켬" 두 번째 측정의 Llama 4건은 브라우저 측 기록을 잃어 미측정 (서버 기록은 있음). 답변 생성은 스트리밍을 쓰지 않아 첫 토큰 시각은 없다 |
| LLM 경로 | gpt-5.4-nano·claude-haiku-5-5, 초기 개발 단계의 API 프록시 경유. 48건 합계 사용량은 프록시 사용 한도의 약 94% |

| 설정·문구·항목 목록 | `common/config.py:28,41,50,56`, `data_prep/items.py:10` (`@lru_cache`) | 아니오 |
| 위키 수집 기록·색인 상태 | `data_prep/wiki.py` `load_log()`, `vectorstore/docs_index.py` `load_status()` | 호출마다 JSON 파일을 읽고 쓴다 |

- 재실행 시작 → 질문 처리 시작 구간은 32건 모두 0.01~0.02초로, 재실행 자체의 비용은 무시할 수준이었다.
- 앱 **시작 시** `rag.graph` import에 6.5초가 걸린다 (`python -X importtime`). `vectorstore/chunking.py`가 `langchain_text_splitters`를 import하면, 이 패키지가 `langchain_text_splitters.sentence_transformers` → `sentence_transformers` → `transformers`·`torch`를 같이 불러오기 때문이다 (4.8초). 질문마다 생기는 비용이 아니라 프로세스 시작 시 1회다.

### 측정 (앱, 파일 감시 켬(기본값), kanana-1.5-8b, 세션 2회)

같은 조건으로 다시 쟀다: 새 콜드 사본(현재 색인 v2에서 위키만 뺀 것) + 프로세스 새로 시작, 질문 순서 Q-a 콜드 → 웜 → Q-b 콜드 → 웜. "개선 전"은 3절 표의 "앱 (파일 감시 켬)" kanana 행 (2026-10-22 측정). "첫 글자"는 브라우저에서 답변 글자가 처음 보인 시각.

| Q-a | 콜드 | 13.8, 22.2 | 13.2, 24.8 | 12.7, 24.1 | 17.8 → 18.9초 |
| Q-a | 웜 | 2.3, 4.8 | 4.2, 3.4 | 3.9, 2.8 | 2.2 → 2.2초 |
| Q-b | 콜드 | 28.6, 12.2 | 32.2, 31.3 | 30.3, 29.9 | 20.2 → 31.7초 |
| Q-b | 웜 | 3.3, 3.2 | 5.4, 17.7 | 3.0, 8.0 | 3.0 → 9.9초 |

| 항목 | 개선 전 (10-22) | 개선 후 (10-23) | 해석 |
|---|---|---|---|
