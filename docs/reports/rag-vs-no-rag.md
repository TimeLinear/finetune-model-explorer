## 1. 라이선스 확인이 우선

EXAONE 3.5 공개 모델은 LG AI Research의 **EXAONE AI Model License Agreement** 아래 배포되며, 제가 알고 있는 버전은 **비상업적(NC) 사용**을 원칙으로 합니다. 정확한 조건은 버전마다 달라질 수 있으니 Hugging Face 모델 카드와 라이선스 원문을 직접 확인하세요.

- **"내부 업무용"은 상업적 이용에 해당할 가능성이 높습니다.** 기업이 업무 생산성을 위해 쓰는 것은 연구·교육 목적과 다르게 해석되기 쉽습니다.
- **파인튜닝 모델도 원 모델의 라이선스를 따릅니다.** 가중치를 수정했다고 자유롭게 쓸 수 있게 되지는 않습니다.
- 라이선스에 파생 모델 배포 시 고지 의무, 라이선스 사본 포함, 명칭 관련 조건 등이 있을 수 있으니 확인하세요.

## 2. 가능한 경로

1. **LG AI Research에 상용 라이선스 문의**: 가장 확실한 방법입니다. 사용 규모, 목적, 배포 형태(온프레미스 여부 등)를 정리해 문의하세요.
2. **사내 PoC는 비상업 범위에서만**: 외부 고객 대응이나 실제 업무 프로세스에 넣기 전 단계로 평가·실험만 하는 방식은 법무 검토 후 진행할 수 있습니다.
3. **라이선스가 자유로운 모델로 대체**: Apache 2.0, MIT 등 상업 이용이 명확히 허용된 오픈 모델(예: Qwen 계열 일부, Mistral 계열 일부 등)을 검토하세요. 한국어 성능이 중요하다면 한국어 특화 모델의 라이선스도 각각 확인해야 합니다.

## 3. 파인튜닝 전에 같이 점검할 것

- **학습 데이터 권리**: 사내 문서, 고객 데이터, 외부 데이터셋의 사용 권한과 개인정보 포함 여부 (개인정보보호법 준수)
- **보안**: 민감 데이터를 외부 API로 보내지 않도록 온프레미스 또는 사내 VPC 배포 검토
- **출력 책임**: 환각(hallucination) 가능성을 고려한 사람 검토 절차, 사용 가이드라인 마련
- **거버넌스**: 모델 버전 관리, 평가 기준, 접근 권한, 로그 관리
