# 항목 텍스트 설계

- 상태: 확정
- 최종 수정일: 2026-10-25
- 관련 문서: [collections.md](collections.md), [decisions.md](decisions.md), [backlog.md](backlog.md), [evaluation.md](../reports/evaluation.md)

## 요약

- 항목(모델) 1건을 어떤 속성으로 묶어 하나의 검색 텍스트로 만들지 정한다.
- 색인 텍스트(임베딩 본문, 답변 근거)와 메타데이터 필터(수치·정확 조건, 정렬)를 나눈다. 근거로 답해야 하는 사실은 메타데이터에 있어도 본문에 넣는다.
- 템플릿은 `config/index_text_template.ko.txt`, 값이 없는 줄은 통째로 뺀다.
- 항목을 서로 구별해 주는 핵심은 모델 소개 요약(한국어 2~3문장)이다.
- 다운로드 수·등록일·가중치 정밀도와 상업 이용 가능 여부 판정은 색인 텍스트에 넣지 않는다.

## 1. 출발점: 사용자는 무엇으로 모델을 찾는가

빠진 속성으로는 검색이 걸리지 않으므로 사용자의 검색 방식에서 거꾸로 정했다. 이 도메인의 대표 검색은 다음과 같다.

> "한국어 되고, 상업적으로 쓸 수 있고, 이미지도 받는, 10B 이하, 긴 문서 처리에 강한 모델"

이 문장을 쪼개면 필요한 속성이 나온다: 지원 언어, 라이선스, 입력 모달리티, 파라미터 수, 컨텍스트 길이, 용도·강점(소개 요약).

## 2. 원칙: 색인 텍스트와 메타데이터를 나눈다

| 구분 | 역할 | 예 |
|---|---|---|
| **색인 텍스트** (임베딩 본문) | 의미 검색에 걸리는 문장. 답변 LLM이 근거로 읽는 사실 | "긴 문서에 강한", "도구 호출 지원", 라이선스 이름, 컨텍스트 길이 |
| **메타데이터 필터** | 정확히 걸러야 하는 조건. 정렬 기준 | "10B 이하", "이미지 입력 가능", "많이 쓰는 순" |

- 임베딩 유사도로는 "10B 이하" 같은 수치 조건을 정확히 거를 수 없다.
- 메타데이터에만 있는 값은 답변 LLM에게 보이지 않으므로, 근거로 답해야 하는 사실은 메타데이터에 있더라도 본문에도 넣는다.
- 상세 배치는 [collections.md](collections.md) 1절.

## 3. 색인 텍스트에 넣는 속성

| 속성 | 출처 | 비고 |
|---|---|---|
| 모델명, 개발사, 개발사 국가 | Hugging Face API | 국가는 코드로 저장, 표시 이름은 라벨 파일 |
| 계열·버전 | 모델 이름 파싱 | 아직 값 없음 (줄이 빠짐, [backlog.md](backlog.md) "항목 보강") |
| 파라미터 수, 구조(Dense / MoE / 상태 공간 모델) | API + config.json | 기계 판독 출처만 사용 |
| 입력 모달리티 | 파이프라인 태그 + 이름 | |
| 학습 단계 (베이스 / 인스트럭트) | 이름 규칙 (+ 카드 기반 보정) | |
| 분야 (범용 / 코드 / 수학 / 의료 / 문서·OCR / 번역) | 이름 규칙 | |
| 지원 언어 | 카드 메타데이터 (+ 카드 기반 보정) | |
| 컨텍스트 길이 | config.json → transformers 기본값 | 출처 문구를 함께 표시 ("설정 파일 기준" 등) |
| 라이선스 이름, 승인 필요 여부 | API | 상업 이용 가능 여부 판정은 넣지 않음 |
| 도구 호출 템플릿 | API (chat_template) | 확인된 경우만 |
| 베이스 모델 | 카드 메타데이터 | 아직 값 없음 (줄이 빠짐, [backlog.md](backlog.md) "항목 보강") |
| **모델 소개 요약** | 모델 카드 → LLM 요약 (한국어 2~3문장) | 영화 검색으로 치면 "줄거리"에 해당. 항목을 서로 구별해 주는 핵심 |

**일부러 넣지 않는 것:** 다운로드 수·등록일·가중치 정밀도(의미 검색에 쓸모없는 숫자, 메타데이터로만), 상업 이용 가능 여부 판정(근거 없는 판단이 데이터로 굳는 것을 막기 위해).

## 4. 템플릿

파일: `config/index_text_template.ko.txt` (언어별 파일, D-08)

```
모델: {model_id} ({vendor}, {vendor_country_label})
계열·버전: {family} {version}
크기·구조: 파라미터 {params_b}B, {arch_label}
입력 모달리티: {modalities_label}
학습 단계: {stage_label}
분야: {category_label}
지원 언어: {languages_label}
컨텍스트 길이: {context_label}
라이선스: {license}{gated_label}
도구 호출: {tools_label}
베이스 모델: {base_model}
소개: {summary}
```

## 5. 렌더링 규칙

1. 값이 없는 줄은 통째로 뺀다. "없음" 같은 빈 표현은 검색 노이즈가 된다.
2. 도구 호출은 확인된 경우(있음)만 적는다. "없음"은 템플릿 위치 차이로 잘못 판정될 수 있다.
3. Mamba 계열은 "상태 공간 모델"로, MoE는 "전문가 N개 중 토큰당 K개 사용"으로 표기한다.
4. 컨텍스트 길이는 출처에 따라 "(설정 파일 기준)" / "(라이브러리 기본값 기준)" / "구조상 고정 길이 제한 없음"으로 표기한다.
5. 표시 문구는 `config/labels.ko.json`에서 가져온다.
6. 미리보기: `python scripts/render_index_text.py data/items_20261021.json <model_id>`
