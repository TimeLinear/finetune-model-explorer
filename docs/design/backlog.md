- [ ] **선별 규칙의 장기 테스트 기준 (빠른 시일 내)** — 지금은 2026-10-21 규칙·데이터를 고정한 회귀 테스트(임시). 규칙이 바뀌어도 쓸 수 있는 기준으로 바꾼다:
  - 규칙별 불변 조건 검사: 제외 패턴에 걸린 모델은 선택되지 않음, 그룹별 선택 수가 비율 공식과 일치, 선택 결과가 그룹 내 다운로드 상위 k와 일치, 크기 범위·중복 제외, 같은 입력에 같은 출력
  - 규칙마다 작은 합성 데이터로 경계 사례 확인 (예: 안전 분류 모델 이름 변형, 공개 30일 미만 다운로드 환산)
  - 기준 결과 파일은 rules_version과 함께 두고, 규칙을 바꿀 때 의도적으로 갱신하며 바뀐 모델 목록을 결정 기록에 남긴다

## 2. 웹 화면·배포

- [ ] 화면 캡처 다시 찍기: 1280px 이상, 질문·답변·근거가 한 화면에, 최신 색인 수
- [ ] Streamlit 메인 페이지 이름을 "app"에서 "질의응답"으로
- [ ] 웹 화면 디자인 다듬기
- [ ] 배포 방식·호스팅 결정 (bge-m3 적재에 필요한 메모리, 카드 색인을 공개 서버에 둬도 되는지)
- [ ] **공개 데모 보호 — 배포 전 필수**
  - 봇 이용 차단, 또는 인증·호출 한도를 갖춘 별도 API 계층으로 분리
  - IP별 속도 제한
  - 일일 예산 상한 (넘으면 데모 질문 중단)
  - 방식은 배포 단계에서 정한다. 제약 없이 공개하면 호출 비용에 상한이 없다.
